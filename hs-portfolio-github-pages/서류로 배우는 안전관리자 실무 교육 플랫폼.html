배경과 목표

수천 개의 안전서류를 법령 순서로 다시 정리하고, 그 서류를 근거로 안전관리자가 알아야 할 법령과 실무를 학습 자료로 풀어냈습니다. 서류를 찾는 도구이면서 서류로 공부하는 교재가 되도록 했습니다.

내가 한 일

  • 중대재해처벌법 시행령 제4조·제5조 기준으로 서류 분류 체계 설계
  • 법령 원문과 사내 절차서를 대조해 불일치·보완 항목 도출
  • 폴더와 문서 본문을 직접 열어 사실 확인, 미확인은 "확인 필요"로 표기
  • 카드·시뮬레이터·퀴즈 등 인터랙티브 화면 설계와 구현

차별점

  • 검증 과정을 드러냄: 일치·보완·확인 필요로 판정을 구분
  • 서류와 학습을 연결: 모든 할 일에 실제 폴더 번호를 배지로 표시
  • 단일 HTML: 설치 없이 열어 보고 모바일에서도 동작

기술과 형식

  • HTML · CSS · JavaScript 단일 파일, 외부 라이브러리 없음
  • 반응형 레이아웃, 키보드·스크린리더 고려
  • 제작 기간 추후 기재 · 역할 추후 기재 · 활용 성과 추후 기재

HOW TO USE이 자료 사용법

폴더 정리는 "서류 공부"를 겸한 작업이었습니다. 그 결과를 안전관리자 눈높이로 풀었습니다.

배우고 나면

  • 법이 요구하는 것이 무엇인지 설명할 수 있다
  • 우리 회사가 어떤 서류로 증명하는지 안다
  • 내가 매달·반기마다 챙길 것을 안다
  • 감독·원청이 요구할 때 바로 꺼낸다

읽는 순서
